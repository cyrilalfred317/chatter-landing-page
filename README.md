# Chatter Landing Page

Chatter is a static landing page for a blogging community where readers and writers can discover content, share ideas, and connect with people who have similar interests. The page introduces the platform and highlights its planned analytics, social interactions, and content creation features.

## Run locally

Open `index.html` in your browser. The page uses plain HTML and CSS, so it needs no package installation, build step, or local server.

The page loads DM Sans from Google Fonts. If the font is unavailable, the stylesheet falls back to Arial or the browser’s default sans-serif font.

## Project structure

| Path | Purpose |
| --- | --- |
| `index.html` | Page markup for the navigation, hero, About section, feature cards, testimonial, community call to action, and footer. |
| `style.css` | Typography, colors, layout, and responsive styles for desktop, tablet, and mobile screens. |
| `assests/` | Local JPG photos and SVG feature icons referenced by the page. |

## Current functionality

The header navigation jumps to sections on the same page. The hero’s **Get started** link opens the About section. The authentication links, other calls to action, and footer links are placeholders. This project contains the landing page only.
